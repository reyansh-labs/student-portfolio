# Chassis model note

The robotics project includes an exported chassis model in the private working repository. I am not copying the binary model into this public portfolio yet, so this page explains what the model represents without pretending that the downloadable file is here.

The chassis was designed in Onshape and used for a 3D-printing stage of the Self-Driving Vehicle project. An STL export shows the shape but not the full parametric design history. I will add a public copy only after checking the file and its sharing permissions.
